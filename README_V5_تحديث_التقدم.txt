تحديث CODM DIGITAL SYSTEM V5 — سجل التقدم والرسوم البيانية

ما الجديد في هذا التحديث:
1) توسيع استمارة تقييم الملاكم لتشمل: الطول، السرعة، القوة، التحمل، المرونة، دقة اللكمات، قوة اللكمات، الدفاع والمراوغة، وحركة القدمين.
2) إضافة رسم بياني خطي لكل ملاكم، مع اختيار المؤشر وعرض القياسات حسب التاريخ.
3) توسيع سجل التقييمات الكتابي لإظهار القياسات الجديدة وملاحظات المدرب.
4) إرسال القياسات الجديدة إلى جدول Supabase progress باستعمال الحقول metric و value و unit الموجودة في بنية الجدول.
5) الإبقاء على الشعار والهوية الحالية، وقاعدة Supabase الحالية، وحساب الرئيس الحالي.

مهم:
- هذا التحديث يطوّر قسم التقدم في لوحة الإدارة الحالية فقط.
- لا تعتبر واجهات الملاكم/ولي الأمر والزوار وطلبات الانضمام مكتملة في هذا الإصدار.
- يلزم اختبار صلاحيات Supabase وتخزين الصور وحسابات المستخدمين قبل إتاحة الموقع للعامة.
- لا تحذفي أو تستبدلي بيانات النادي. احتفظي بنسخة احتياطية قبل نشر أي تحديث.

طريقة التحديث لاحقاً:
استبدال ملفات الموقع بالملفات الموجودة داخل مجلد CODM_DIGITAL_SYSTEM بعد أخذ نسخة احتياطية، ثم رفعها إلى مستودع GitHub Pages الحالي.
