تحديث CODM — نشر الإعلانات بالصور

ما الجديد؟
- قسم جديد باسم «الإعلانات» داخل القائمة.
- نشر إعلان نصي أو بصورة أو الاثنين معاً.
- رفع الصور إلى Supabase Storage حتى تظهر على الأجهزة الأخرى.
- عرض الإعلانات المحفوظة من جدول announcements.
- الحد الأقصى للصورة 5 ميغابايت، والصيغ JPG وPNG وWEBP.

قبل الاستخدام:
1) افتحي Supabase الخاص بالنادي.
2) افتحي SQL Editor ثم New query.
3) افتحي الملف sql/SETUP_ANNOUNCEMENT_IMAGES.sql وانسخي محتواه إلى SQL Editor.
4) اضغطي Run وانتظري ظهور Success.
5) افتحي index.html من هذه الحزمة أو ارفعي الملفات إلى موقع GitHub Pages لاستبدال النسخة المنشورة.
6) سجلي الدخول بحساب الرئيس، ثم افتحي «الإعلانات» وجربي نشر إعلان.

مهم:
- لا تحذفي جداول قاعدة البيانات ولا حساب الرئيس.
- هذا التحديث لا يغيّر كلمة المرور أو بيانات الملاكمين.
- قبل استبدال نسخة الموقع المنشورة، احتفظي بنسخة احتياطية من بياناتك من قسم «النسخ الاحتياطي».
- إذا كان موقع GitHub Pages يستخدم نسخة أخرى من النظام، ارفعي مجلد CODM_DIGITAL_SYSTEM كاملاً مع الاحتفاظ بأسماء الملفات وبنية المجلدات.
