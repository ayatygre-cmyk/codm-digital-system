CODM DIGITAL SYSTEM — تحديث V5

يتضمن هذا التحديث:
1) سجل التقدم البدني والتقني مع رسوم خطية حسب الملاكم والمؤشر والتاريخ (من V5 السابق).
2) واجهة عامة للزوار تعرض الإعلانات العامة المنشورة فقط.
3) نموذج طلب انضمام منفصل؛ لا يضيف أي شخص تلقائياً إلى قائمة الملاكمين.
4) إعدادات SQL لقراءة الإعلانات العامة وإرسال طلبات الانضمام مع حصر قراءة الطلبات وتعديلها في حسابات طاقم النادي.
5) الحفاظ على حساب الرئيس الحالي ودور president؛ لا ينشئ حساب مدرب منفصلاً.

مهم قبل النشر:
- احتفظي بنسخة احتياطية من مستودع GitHub وبيانات Supabase.
- افتحي Supabase > SQL Editor، والصقي محتوى sql/SETUP_PUBLIC_REQUESTS.sql ثم Run مرة واحدة.
- يجب أن تكون سياسة قراءة announcements الحالية لا تمنع anon؛ ملف SQL يضيف سياسة عامة للقراءة.
- يجب أن تكون بيانات الإعلانات عامة فقط. لا تضعي معلومات شخصية للملاكمين في تفاصيل الإعلان.
- نموذج الانضمام يرسل الطلبات إلى membership_requests. المراجعة والإقرار بالموافقة أو الرفض يتمان حالياً من جدول Supabase مباشرة؛ واجهة إدارة الطلبات داخل لوحة CODM لم تُضف بعد.
- لا تتضمن هذه النسخة بعد حسابات دخول الملاكمين/الأولياء أو ربط ولي الأمر بالملاكم. لا تُعتبر هذه الوظائف مفعّلة حتى تُبنى وتُختبر منفصلة.
- صور الإعلانات تعتمد على إعداد الحاوية codm-announcements في ملف sql/SETUP_ANNOUNCEMENT_IMAGES.sql الموجود في مجلد sql.

اختبار أولي:
1) بعد تنفيذ SQL، افتحي رابط الموقع في نافذة خاصة/متصفح آخر.
2) اختاري «الدخول كزائر / طلب الانضمام».
3) تحققي من ظهور الإعلانات العامة وإمكانية إرسال طلب تجريبي.
4) تحققي من ظهور الطلب في Supabase > Table Editor > membership_requests.
5) سجلي الدخول بحساب الرئيس للتأكد من بقاء لوحة الإدارة كما هي.

تنبيه: لم يتم إجراء اختبار اتصال حي بقاعدة بيانات النادي أو إنشاء حسابات أولياء الأمور في هذه الحزمة.
